# Function Layer

F-keys, controles de sistema, y RGB.

## Activación

- Hold thumb izquierdo inner (gresc) desde base

## F-Keys

Mano derecha, layout 3x4:
```
F7  F8  F9  F10
F4  F5  F6  F11
F1  F2  F3  F12
```

F13-F15 en column exterior.

## System Controls

| Tecla | Función |
|-------|---------|
| Row 1 | Windows shutdown macro |
| Q | Pause/Break |
| W | Scroll Lock |
| E/R | Undo/Redo |
| T | Print Screen |
| Caps | Caps Lock toggle |

## Modifiers (mano izquierda)

Home row con modifiers para F-key combos:
- A: GUI
- S: Alt
- D: Ctrl
- F: Shift

## Hyper Key

- **G**: RGB toggle
- **Row derecha**: Hyper key sticky (Ctrl+Shift+Alt+GUI)

## Brightness

Row inferior derecha:
- Max / Inc / Dec / Min / Auto brightness

## Media

- Mute, Vol down, Vol up en thumbs
- Play/Next/Prev tap-dance

## Otros

- **Lock**: Tap-dance (1t: Win+L, 2t: Win+Esc)
- **Screensaver**: K_SCREENSAVER
- **NumLock**: Disponible

## Dependencias

- `lock_td` — tap-dance
- `windows_shutdown` — macro con timing
- `play_next_prev_td` — tap-dance media
