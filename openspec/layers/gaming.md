# Gaming Layer

Layout optimizado para gaming con layer auxiliar para números.

## Activación

- Combo: 4 teclas específicas (posiciones 50+48+37+69)
- Require prior idle 500ms (evita activación accidental)
- Solo desde base layer

## Layout Principal (Layer 6)

WASD reposicionado para ergonomía Glove80:
```
    Q W E R
TAB A S D F
SHFT Z X C
```

### Cambios vs Base

- **Tab**: Posición cómoda para abilities
- **Shift**: Posición natural para sprint/crouch
- **Ctrl**: Disponible en thumb
- **Space**: Thumb principal — jump/confirm
- **Escape**: Thumb inner — menu/cancel

### Mano Derecha

- **IJKL**: Arrows (para menús)
- **Resto**: Toggles para salir del layer

## Layer Auxiliar (Layer 7)

Acceso a números para hotbars/abilities:

```
        4 3 2 1 0
    9 8 7 6 5
```

- Activación: Hold en thumb (Alt position)
- Key repeat disponible para abilities con cooldown

## Features Gaming

- **Sin home-row mods**: Evita delays en inputs
- **Sin tap-dance complejos**: Respuesta inmediata
- **Pause/Break**: Disponible para pausar
- **Caps Lock**: En layer aux para voice chat

## Salir del Layer

- Múltiples teclas "tog 6" en mano derecha
- Mismo combo de entrada

## Dependencias

Ninguna especial — layout directo sin behaviors complejos.
