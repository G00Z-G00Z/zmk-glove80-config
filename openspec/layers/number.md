# Number Layer

Numpad en mano derecha, operadores matemáticos, y símbolos comunes.

## Activación

- Hold thumb izquierdo outer (shift tap-dance) desde base
- Toggle disponible

## Layout Numpad

Mano derecha, estilo calculadora:
```
7 8 9
4 5 6
1 2 3
  0
```

## Operadores

| Tecla | Símbolo |
|-------|---------|
| H row | + |
| J row | - |
| Arriba 7 | % |
| K row | * |
| Bottom | / |
| Thumb | . , |

## Símbolos Adicionales

- **$ # @ !**: Row superior derecha
- **^ |**: Disponibles
- **Tilde ~**: Corner

## Mano Izquierda

- **Home row mods**: Disponibles (GUI/Alt/Ctrl/Shift)
- **AM macro**: A con hold → escribe "am" (para horas)
- **Undo/Redo**: Disponibles
- **Ctrl+A**: Select all

## Combos Activos

- Backspace: teclas adyacentes mano derecha
- Space: teclas adyacentes mano derecha

## Dependencias

- `am_hrm_behaviour` — hold-tap especial para "am"
- `two_kp` — macro para PM
- `extend_word`, `extend_line` — disponibles
