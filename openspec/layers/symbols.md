# Symbols Layer

Símbolos de programación optimizados para acceso rápido.

## Activación

- Hold thumb derecho outer (space) desde base
- Toggle disponible

## Layout Principal

### Brackets (mano izquierda)
```
{ [ ] }
( < > )
```
Con mod-morph: tap = `[]`, shift = `{}`; tap = `()`, shift = `<>`.

### Símbolos Frecuentes

| Posición | Símbolo | Notas |
|----------|---------|-------|
| Top row | ` ' " ~ ; | Quotes y terminadores |
| Home row izq | # ^ $ * | Símbolos de código |
| Bottom row izq | @ \| = _ - ? | Operadores y puntuación |

### Mano Derecha — Modifiers

Home row derecha tiene modifiers puros para combinar:
- J: Shift
- K: Ctrl  
- L: Alt
- ;: GUI

Esto permite escribir símbolos y aplicar modifiers en la misma mano.

## Símbolos Adicionales

- **Semicolon, dot, comma**: Accesibles sin salir del layer
- **Space, Backspace**: En combos
- **Paste**: Disponible

## Combos Activos

- Space: teclas adyacentes
- Backspace: teclas adyacentes
- Brackets: mismos combos que en base

## Dependencias

- `lpar_lt`, `rpar_gt` — mod-morphs para paréntesis
- `lbra_cur`, `rbra_cur` — mod-morphs para brackets
